# 魚樂無窮

供小學晨讀使用的本機瀏覽器程式。預設繁體中文，以全畫面像素水族館呈現；50 種生物、珊瑚、海草、水波與光線均有動畫。畫面只保留右上角的本節代幣、「暫停」和「設定」圖示。

## 開啟

從 GitHub 選擇 **Code → Download ZIP** 並解壓縮，或直接[下載單檔離線版](https://github.com/Cfsthk/fish-fun/raw/refs/heads/main/Morning%20Reef.html)。

在 Chrome 或 Edge 開啟 **Morning Reef.html**，先按 **1–6** 選擇年級，再按 **信／望／愛／智** 選班。允許瀏覽器使用麥克風後，水族館便會自動運作，毋須另按開始。單一 HTML 已包含程式和全部圖片，可離線使用，亦可複製到課室電腦。

沿用同一個瀏覽器、使用者設定檔及檔案位置。部分學校的瀏覽器政策可能限制本機檔案收音；這種情況可使用下面的 localhost 版本，或以 HTTPS 提供原始檔。

## 課室操作

- 每節一開始便有一條隨機常見魚，亦會計入本節訪客及圖鑑。允許收音後，每累積 45–60 秒合適的安靜音量便會再迎來一位訪客；同種生物可以同時出現多隻。
- 超過上限時，全體生物立即加速並向不同方向慌張游動，畫面上方的波浪線加劇；背景不會因噪音扭曲或變暗。持續超標 **1 秒**開始有生物離開，其後每持續 **1 秒**再離開一批。聲音越大，離開的生物越多；稀有生物較容易受驚。水族館至少保留一條魚：先選最低稀有度，再保留該級別中最新到訪的個體。牠仍會慌張游動，但不會因噪音離開。
- 回落至上限以下便停止新增離開事件。需連續安靜 **10 秒**讓水面恢復，才繼續累積訪客進度；之前累積的進度會保留。
- **暫停**會完全定格生物、轉身、珊瑚、海草、水波、氣泡和光線，同時暫停收音、到訪進度和代幣累積。彈出視窗提供「繼續」、「重新開始」、「結束本節」。
- **重新開始**會儲存本節紀錄，代幣歸零，並以一條新的隨機常見魚開始；已解鎖圖鑑會保留。**結束本節**會列出所有到訪種類、次數、新發現及本節代幣，並提供「圖鑑」按鈕。
- 本節沒有固定時限，由老師按「結束本節」手動結束。生物上限預設 20 隻；畫面不顯示時鐘、音量表或下次到訪倒數。

安靜和輕聲朗讀都能累積進度；是否正在閱讀由老師觀察。本程式不辨識語音內容。

## 本節代幣

選班及連接收音後開始累積，右上角顯示已賺取的整數代幣，小數進度會保留。只計算仍留在缸內的生物；同種多隻分別計算，只游過或已離開的訪客不增加收入。生物越多、稀有度越高，代幣增加越快；收入有遞減增幅，避免單次幸運訪客令獎勵失衡。生物受驚離開會降低之後的增加速度，已賺取的代幣會保留。

五級生物的權重依次為 **1、1.4、2、3、4**。設缸內權重總和為 `P`，每分鐘收入為 `3.6 × (1 − exp(−P / 5))`，按實際運作秒數累積；**每節最多 150 枚**，達上限後水族館仍繼續運作。暫停、設定、圖鑑、離開分頁、收音中斷或本節結束期間均不累積。重新開始或換班會開始新節，代幣從零計算；已結束課節的代幣隨該班訪客紀錄儲存。

以預設 20 隻上限、約 **30 分鐘**為平衡基準，1,000 次各情境的模擬平均：安靜 **96.4 枚**、偶爾持續超標 **71.7 枚**。這是平均目標，並非每節保證；短課節或經常吵鬧會較少。課節仍由老師手動結束，延長亦不會突破 150 枚。

## 設定與班別

所有教師控制均放在設定內，包括班別、語言、音量上限、12 秒校準、生物上限、減少背景動畫、全螢幕和圖鑑。設定已移除「晨讀紀錄」及「資料備份」區塊。

內置 **24 班**：P.1–P.6 × 信／望／愛／智；切換英文後顯示 F／H／L／W。每班有獨立圖鑑和音量校準。切換班別會儲存原班本節，並為新班以一條隨機常見魚開始新節。關閉設定後自動繼續。

每次開啟都先選年級，再顯示該年級的四個班；上次使用的年級會取得初始鍵盤焦點。按其他年級數字可直接更換四個班別選項。完成選班前不會建立本節、解鎖生物或啟用麥克風。按班別後才為該班迎來第一條隨機常見魚。選擇頁不能以 Esc 或按背景略過，語言沿用上次設定。

首次使用採用預設音量上限。建議先在設定內選擇「校準讀書聲」，讓學生以理想音量朗讀 12 秒，程式會自動套用上限；亦可用「較安靜／較寬鬆」滑桿調整。設定內不會顯示即時音量表。更換電腦、麥克風或擺放位置後宜重新校準。

生物上限可設 10–40 隻，於下一節生效。切換至其他分頁或應用程式時也會暫停，回來後由暫停視窗繼續。

## 生物與圖鑑

50 種可游動的生物分為常見、少見、稀有、珍稀、傳奇五級，每次到訪的級別機率分別為 **54%、27%、13%、5%、1%**，同級種類機率相同。稀有訪客並非每節保證出現。海星等移動緩慢的舊生物不再成為新訪客，舊版生物的已存資料仍會保留。

未發現的種類以深色剪影顯示。任何到訪都會永久解鎖該班圖鑑，包括後來逃走、或因滿額而只游過的生物。

滿額時，新訪客只能替換相同或較低稀有度的居民；依次選擇最低稀有度、該稀有度中數量最多的種類、最早到訪的個體。若全缸居民都更稀有，新訪客只游過，仍計入到訪紀錄與圖鑑。

所有生物均以同一個像素網格繪製；大小、深度和轉身不會改變像素密度。大生物使用更多像素，小生物使用較少像素。生物只使用左右側面。轉向會先減速，在接近零速時切換方向，再逐步加速，不會顯示正面或擠壓魚身。平靜時以橫向巡游為主，接近缸邊折返，偶爾提早轉向，深度只會緩慢漂移；受驚時也以橫向移動為主。

七種主要大型生物已重製成更高解析的硬邊像素素材，並移除輪廓的半透明模糊邊，讓大、小生物的像素顆粒一致。雙髻鯊使用扁平頭部側面。座頭鯨、虎鯨和海豚會以上下擺動尾柄及尾鰭推進，頭部保持穩定；暫停時尾部亦會定格。

生物已按體型調大：一般魚約放大兩成，中型生物放大約四分之一至四成；珍稀的大型生物約放大四成至七成，傳奇鯨類及鯨鯊約放大八成至九成。座頭鯨最大，其次為鯨鯊和虎鯨；麒麟魚仍維持小型魚比例。這是適合水族館畫面的壓縮比例，並非真實公尺比例。大型生物使用更多同樣大小的像素，保持清晰；游動及離場範圍會計入完整魚身、轉向及魚鰭擺動。

生物按完整輪廓獨立裁切，魚鰭、尾巴和觸鬚即使跨過原圖格線也會保留；裁切範圍內的鄰魚碎片會被排除。水族館、訪客名單及圖鑑共用同一份完整圖像。

原始碼伺服器運作時，可開啟 [體型預覽](http://localhost:4173/size-preview.html)，同場比較五種普通魚、黑鰭礁鯊、雙髻鯊、座頭鯨及虎鯨。預覽沿用正式繪圖程式、體型及像素密度，預設靜止，右上角可播放或暫停；不會收音或更改任何班的收藏。[最新靜態預覽](size-comparison-v3.png)以 1920 × 1080 保存；舊版 `size-comparison.png` 保留供比較。

每種生物有自己的平靜游速範圍，同種不同個體有各自偏好的速度。每條魚亦會在該範圍內緩慢加快或放慢，並以平滑加減速銜接。轉身時可減速至接近零；受驚逃走時則會加速。這些範圍用於水族館動畫，並非真實生物的測量速度。

背景沿用最初版本的珊瑚、岩石與沙地設計。原有珊瑚及海草以局部動畫輕微擺動，不再疊加第二版的大型植物素材。

## 儲存與私隱

麥克風只在本機分析音量，不錄音、不播放、不上傳，也沒有學生帳戶。上限採用相對麥克風音量，**不是經校準的物理 dB SPL**。

圖鑑進度儲存在本機瀏覽器；清除瀏覽器資料、轉換瀏覽器、設定檔、網址連接埠或檔案位置可能無法沿用。設定不再提供歷史紀錄或備份功能。本節結束後可查看訪客名單及圖鑑。

新版使用獨立的 `morning-reef-v2` 儲存空間，首次可承接 V1；原有 V1 資料不會被刪除。舊版「Class A」會對應至 P.1 信；其他舊自訂班別保留在「其他班別」。被移除生物的舊收藏與歷史亦會保留。

## 執行或修改原始碼

需要 Node.js 20 或以上，毋須安裝套件。

```sh
npm start
```

在 Chrome／Edge 開啟 **http://localhost:4173**，並保持終端機執行。若連接埠已被使用，可執行 `PORT=4174 npm start`，並使用 `http://localhost:4174`。不同連接埠有不同的瀏覽器資料空間。

`index.html` 的模組版需要本機伺服器；`Morning Reef.html` 可直接開啟。此版本尚未部署至公開網站。所有字型、程式和圖片均無外部網絡依賴；localhost 版首次成功載入後也會快取原始檔。

修改後執行：

```sh
npm test
npm run build
```

`npm run build` 會重建包含所有素材的單一 HTML。測試及瀏覽器檢查詳見 `QA.md`；課室實際收音、投影效果和學校電腦效能仍需實地試用。

## 主要檔案

- `engine.mjs`：到訪、逃走、稀有度、容量、代幣和本節紀錄規則。
- `motion.mjs`：二維游動、全體慌張及雙向轉身。
- `scene.mjs`：像素素材、水波、光線、珊瑚與海草動畫。
- `sprite-crops.mjs`：按完整輪廓分離生物，保留跨格部位並排除鄰魚碎片。
- `microphone.mjs`：本機音量分析與麥克風生命週期。
- `app.mjs`、`style.css`、`index.html`：沉浸式畫面和教師視窗。
- `store.mjs`：24 班資料、V1 資料相容及儲存驗證。
- `build.mjs`、`Morning Reef.html`：打包工具與課室單檔版本。
- `size-preview.html`、`size-preview.mjs`、`size-comparison-v3.png`：最新體型、尾部動畫及像素清晰度比較；`size-comparison.png` 保留舊版畫面。
- `assets/ARTWORK.md`：內置 imagegen 素材、用途和生成提示詞。
- `archive-v1/`：修改前的 V1 原始檔，供參考。
